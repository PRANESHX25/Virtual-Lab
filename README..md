# 🧪 Cheminformatics Virtual Laboratory

Interactive virtual laboratory app built with Python, Streamlit, and RDKit, featuring Dark/Light mode toggle, extra control buttons, molecular property calculations, 3D interactive visualizations, and automated PDF report generation.

## Features
- **Dark & Light Mode:** Toggle themes directly from the sidebar control panel.
- **Extra Control Buttons:** Quick Reset, Theme Toggle, Quick-Load presets (Ethanol, Caffeine, Aspirin), and Clear inputs.
- **Molecule Viewer:** 2D drawing and interactive 3D rendering (`py3Dmol`).
- **Property Analysis:** Automated calculation of Molecular Weight, LogP, TPSA, H-bond donors/acceptors, and bond counts.
- **Reporting:** Export individual or multi-molecule reports as CSV or formatted PDF.
